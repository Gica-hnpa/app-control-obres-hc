# APP Control d'Obres · V87.100 refinament professional

Base: V87.99 mòduls refinats.

Canvis:
- Capçalera de certificació/proforma amb logo i nom fiscal de l'emissor.
- Impressió/PDF prioritària en certificacions i proformes.
- Fitxa de clients més neta, amb NIF/CIF fiscal i província.
- Biblioteca d'agents editable dins actes.
- Ajustos visuals de modal/document per PC, iPad i mòbil.

Render:
- Static Site
- Build Command: npm install --no-audit --no-fund --legacy-peer-deps && npm run build
- Publish Directory: dist

No pujar node_modules ni package-lock.json.
