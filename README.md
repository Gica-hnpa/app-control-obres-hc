# APP Control d'Obres · V87.132

Versió derivada de V87.131.

Canvis principals:
- El botó Treure cert. ara retira visualment la partida de la certificació actual sense eliminar-la del pressupost base.
- Afegit botó per mostrar/amagar partides retirades i recuperar-les si cal.
- La impressió de certificació ja no mostra descripcions llargues.
- La certificació impresa agrupa les partides per capítol i ordena per capítol/codi.
- La vista de certificació ordena les partides i permet canviar codi/capítol en mode edició.
- Botó visible per imprimir el quadre d'administració mensual guardat de la certificació.
- Es manté el sistema de quadre d'administració justificatiu amb resum per conceptes/materials.
