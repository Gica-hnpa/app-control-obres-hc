# APP Control d'Obres · V87.76

Millores principals:
- Capçalera d'expedient més neta: només codi, nom, client, tipologia i estat; dades completes dins la pestanya Dades.
- Pressupostos i factures globals del tècnic amb filtres per període, obra, client i tipologia.
- Gràfics circulars d'estat de pressupostos i factures.
- Avisos automàtics de factura pendent de cobrament passats 7 dies, visibles a Inici i Agenda.
- Gestió del temps global amb vista per defecte del mes en curs, gràfiques per client i tipologia, registre resum i totals.
- Dates visibles en format dd/mm/aaaa.

Build: npm install --no-audit --no-fund --legacy-peer-deps && npm run build
Publish: dist
