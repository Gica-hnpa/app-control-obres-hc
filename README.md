# APP Control d'Obres · V87.96

Versió de refinament sobre V87.95.

Canvis principals:
- Previsualització de certificació i proforma més neta, sense capçaleres duplicades i amb més marge superior perquè no quedi tallada.
- Impressió/PDF de certificació amb marges més segurs per evitar tallar la capçalera.
- Imports i quantitats alineats a la dreta en proformes, certificacions i totals.
- Capçalera de l'expedient més neta: les dades i modificacions es concentren a la pestanya Dades.
- Resum d'expedient amb darreres actuacions reals: certificacions, factures, pressupostos, actes, agenda, temps i partides modificades.
- Login compatible amb gestor de contrasenyes del navegador i clauer/biometria del dispositiu si està configurat.
